# TrendForge
A polished, responsive static website focused on AI, gaming, technology, creator trends, apps and internet culture.

## Run
Open `index.html` in a browser.

## Publish free
Upload the files to GitHub Pages, Netlify, Vercel, or another static hosting provider.

## Customize
- Change the content in `index.html`
- Change colors/spacing in the CSS variables at the top of the `<style>` section
- Replace demo trend cards with your own content
- Connect the newsletter button to a real form service when you're ready
